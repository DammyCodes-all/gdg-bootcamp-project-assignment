## 📥 Getting Started

Follow the steps below to clone and set up the project on your local machine:

### 1. Clone the Repository
```bash
git clone <repository-url>
```

### 2. Navigate into the Project Folder
```bash
cd <project-folder-name>
```
### 3. Get to work 👌


## Your task is to complete the following functionalities:

### ✅ Assignment Tasks

- **Integrate the Signup API**  
  Simulate user creation by integrating the signup API (note: the user won't actually be created on a backend — this is for practice).

- **Fetch Products from Fakestore API**  
  Retrieve and display products using the [Fakestore API](https://fakestoreapi.com/).

- **Create a Cart Page**  
  Display all items added to the cart. The cart data should be stored in **local storage**.

- **Implement Logout Functionality**  
  Make the Logout button functional by clearing user session or data as appropriate.
